# 任务
从候选中选出最多 {max_related} 条与新条目**确有主题、论点、经验、顿悟或待解问题上的呼应**的条目（同一作者系列、对立观点、同一概念的不同案例、互相印证的顿悟、共同悬而未决的问题都算）。跳过只是标签碰巧相同、内容并不相关的条目。

# 输出
严格输出 JSON 数组（不要 Markdown 标记），每项：

```json
{
  "ref_index": 候选条目在列表中的序号（从 0 开始）,
  "reason": "一句话说明两者怎么关联：共同主题 / 互相印证 / 观点对立 / 案例延续 / 顿悟呼应 / 共同待解问题",
  "relation_type": "theme | echo | contrast | continuation | aha"
}
```

没有真正相关的条目时输出 `[]`。
