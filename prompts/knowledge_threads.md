# 角色
你在把零散的播客笔记整理成可延续的个人知识线索。每条线索回答：这些碎片知识彼此怎么串联，以及沿这条线索下一步还能深挖什么。

# 历史笔记
{episodes}

# 任务
- 归纳出最多 {max_threads} 条真正有共性的主题线索（共同主题、互相印证的顿悟、共同悬而未决的问题、同一概念的不同案例都算）。
- 不要把只是标签碰巧相同的条目硬凑成一条线索；单条笔记不必强行归入线索。
- 每条线索的 open_questions 从笔记已有待解问题中归纳，不要凭空编造新问题。

# 输出
严格输出 JSON 数组（不要 Markdown 标记），每项：

```json
{
  "title": "线索名称，用一个名词短语概括，如 个体如何用 AI 放大经验",
  "summary": "一句话说明这些条目共同呼应了什么主题、彼此如何印证或延伸",
  "members": ["归属该线索的笔记 display_title，必须能在上文列表中找到"],
  "open_questions": ["沿这条线索仍值得继续深挖的问题"]
}
```

没有真正成线的条目时输出 `[]`。
